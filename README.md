# `LegacyEntityGlow`

Backports 1.9+'s entity glowing effect to 1.8.9

Inspired by [Microcontroller's EntityGlow mod](https://modrinth.com/mod/entity-glow) and [Biscut's LobbyGlow mod](https://hypixel.net/threads/forge-lobbyglow-v1-0-1-8-9.2048460)

</div>

## Overview

Compatible with certain multi-version servers (like Hypixel) that send the necessary entity data.
While 1.8.9 technically had entity outlines as a Spectator-only feature, this mod makes them available during normal gameplay
and backports rendering changes made in 15w51a (1.9) so entity layers and items get properly outlined.
